# Moodly Project

## Язык

Все агенты должны предоставлять информацию только на русском языке. Это касается всех ответов, комментариев к коду, документации и любых других текстовых сообщений.

## Стек

- Backend: Go 1.22+
- Frontend: React + TypeScript + Vite
- Database: PostgreSQL + Prisma
- Infrastructure: SST (Serverless Stack) на AWS

## Визуальные элементы

Перед реализацией любого визуального компонента (React-компонент, UI-элемент, лейаут, анимация, схема расположения блоков) агент **обязан** нарисовать SVG-макет с размерами, отступами и расположением элементов — **на этапе планирования, до написания кода**.

Последовательность:
1. **Планирование** — агент рисует SVG-макет, сохраняет в `docs/` и открывает в браузере для визуальной оценки
2. **Обсуждение** — пользователь смотрит макет и вносит правки; при необходимости агент рисует новые версии макета
3. **Утверждение** — только после того, как макет утверждён, агент приступает к реализации компонента в коде

Исключение — только если макет уже существует или пользователь явно отказался.

## Отчёт об изменениях кода

После завершения любого рефакторинга, переписывания компонента или массового изменения кода агент **обязан** предоставить отчёт об изменении объёма кода:
- количество добавленных строк
- количество удалённых строк  
- чистый результат (дельту)

Для подсчёта использовать `git diff --stat` или `wc -l` по изменённым файлам. Отчёт выводится текстом без комментариев.
