# Питомцы (Lottie-анимации)

Папка-приёмник питомцев. **Каждый питомец — отдельная подпапка**, внутри — его JSON-файлы анимаций. Данные подтягиваются автоматически через `import.meta.glob` (`frontend/src/features/gamification/pets.ts`).

## Структура

```
pets/
├── Котик/
│   ├── pet-kitty-1.json
│   └── pet-kitty-2.json      ← несколько анимаций одного питомца (рендерится случайная)
└── Жираф/
    └── pet-giraffe-1.json
```

## Как добавить питомца

1. Создай подпапку с именем питомца (например, `Лиса/`) и положи в неё JSON-файл(ы) анимации.
2. Перезапусти dev-сервер, если питомец не появился сразу.

Ничего больше не требуется: питомец появится в коллекции, аватарах и практике «Дыхание». Имя папки используется как имя питомца; эмодзи — 🐾, цвет фона — по кругу из `bg-pet-1..7`.

## Настройка (по желанию)

- **Латинский тип** (нужен, если тип питомца участвует в разблокировке/наградах): добавь запись в `FOLDER_TO_TYPE` в `pets.ts`, например `"Лиса": "fox"`. После этого имя задаётся через перевод `pets.fox` в `frontend/src/i18n/locales/{ru,en}/translation.json`.
- **Свой эмодзи/цвет**: добавь запись в `PET_META` в `pets.ts` (ключ — тип питомца).
- **Порядок в коллекции**: укажи тип в `KNOWN_ORDER`.

## Разблокировка

Новый питомец будет в коллекции, но **заблокирован**, пока его тип не попадёт в `unlockedPetTypes` у пользователя (стартовый набор: `puff`, `dewdrop`, `sprout` — в `STARTER_PET_TYPES`). Разблокировать можно:

- наградой за достижение — `petTypeReward` в `backend/src/seed.ts`;
- для демо-аккаунта — добавив тип в `unlockedPetTypes` демо-пользователя в `backend/src/seed.ts`.
